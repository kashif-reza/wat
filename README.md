# ISSB Word Association Test (WAT) Practice

A lightweight browser-based practice tool for the **Word Association Test (WAT)** used during ISSB preparation. It displays a random word and gives the user a 10-second window before moving to the next word, with a short beep alert.

## Features
- Start the practice session with one click
- Random word display
- 10-second countdown for each word
- Audio beep when the time ends
- Simple, focused single-page interface

## Run
This is a standalone HTML file; no package installation is required.

1. Clone or download this repository.
2. Open `wat.html` in a modern browser.
3. Press **Start** to begin.

## Technology
- HTML
- CSS
- Vanilla JavaScript
- HTML Audio

## Project Status
A basic practice prototype. The current word list is a small starter set and can be expanded for broader practice.
